# Godson V O — Personal Portfolio

A modern, responsive personal portfolio website built from scratch using **HTML, CSS, and JavaScript**.

The portfolio showcases my skills, education, projects, and contact information while experimenting with interactive UI effects and animations.

## 🔗 Live Demo

👉 Visit My Portfolio: https://godsonvo-portfolio.vercel.app/

## 🚀 Features

- Responsive design for desktop, tablet, and mobile
- Modern blue gradient hero section
- Custom interactive cursor
- Animated cursor hover and click effects
- Interactive social media buttons
- Smooth scrolling navigation
- Responsive mobile navigation menu
- Animated proficiency progress bars
- Interactive project cards
- Education section
- Contact section with social links
- Resume viewing button
- Back-to-top button
- Custom favicon
- CSS animations and hover effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- CSS Animations
- Intersection Observer API
